# Princípios da interface

1. O viewport é o centro do editor e não recebe sobreposição permanente de instruções.
2. Cada workspace possui uma barra contextual curta, baseada em ícones com tooltip.
3. A hierarquia fica à esquerda; o inspector contextual fica à direita; assets e saída ficam no painel inferior recolhível.
4. Propriedades são agrupadas em seções recolhíveis.
5. Ações destrutivas ficam separadas das ações frequentes.
6. Cores sólidas substituem gradientes decorativos.
7. Texto é usado para nomes, valores e contexto; comandos frequentes usam ícones.
8. Navegação e edição nunca disputam o mesmo gesto.
