# Mobile NoCode World

Projeto de validação do runtime NoCode nativo no Godot mobile.

- Mundo plano com colisão.
- `CharacterBody3D` com câmera em terceira pessoa e `SpringArm3D`.
- Joystick multitoque e botão de pulo.
- Movimento, gravidade, velocidade, câmera por arrasto e pulo executados por `MGSNoCodeRunner`.
- Grafo editável salvo em `main.graph.json`.

No desktop, use WASD/setas e Espaço. No Android, use o joystick esquerdo, arraste o lado direito para olhar e toque no botão PULAR.
